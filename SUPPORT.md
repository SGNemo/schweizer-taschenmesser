# Support

## Getting help
- **Docs first:** [Installation](docs/user/installation.md), [Sync](docs/user/sync.md), [Backup](docs/user/backup.md), [Search and AI](docs/user/ai-assistant.md), [Security](docs/user/security.md), [FAQ](docs/user/faq.md). German versions sit next to them (`*.de.md`).
- **Something broken?** Open an issue with the "Bug report" template. Please include the version (Settings → App updates) and platform, and never real data in screenshots or logs.
- **An idea?** Use the "Feature request" template. Check the [roadmap](docs/ROADMAP.md) first.
- **Wrong or odd translation?** Use the "Translation" template.
- **Security problem?** Do not open a public issue; follow [SECURITY.md](SECURITY.md).

Nemo is a hobby project maintained by one person. Answers can take a few days, and there is no guaranteed support.

## Supporting the project
Nemo is free and every feature is open to everyone. If you want to say thanks, you can support it on [Ko-fi](https://ko-fi.com/nemojr). As a thank-you you get a supporter code that unlocks purely cosmetic extras; nothing is ever behind a paywall. Details: [README](README.md#support).
