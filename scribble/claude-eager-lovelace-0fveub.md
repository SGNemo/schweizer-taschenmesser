# claude/eager-lovelace-0fveub – T5 capture & presence (all 3 packages, one PR) – for the next chat:

- **Android shortcuts/tile are unbuilt locally:** no Android SDK in the cloud container. Gradle only runs after merge: job "Android APK (dev)" in `dev-preview.yml` (after a green push to `develop`) and "Android APK" in `release.yml` (dry run on `develop` pushes touching `web/src-tauri/**`). If that job fails on `shortcuts.xml`/`CaptureTileService.kt`, the fix belongs in `src-tauri/plugins/share-intent/android/**`. Hand tests Q1–Q3 in `docs/MANUAL-TESTS.md`.
- **`${applicationId}` does not work in res XML.** `shortcuts.xml` names the stable id; `scripts/android-shortcuts.mjs <tauri config>` rewrites `targetPackage`/`targetClass` right after `tauri android init` (both workflows). `scripts/lib/androidShortcuts.test.ts` pins this – a new workflow that builds an APK needs the same step.
- **Android strings:** escape apostrophes (`Aujourd\'hui`), aapt2 fails otherwise; the test checks it.
- **Multi-line capture:** `parser/split.ts` is all-or-nothing per line (every part must read as an entry). If users report a missed split, add a case to `split.test.ts`; the corpus guard there must stay green (one line = same reading as before).
- **CaptureForm is a `<textarea>` now.** Enter saves (all devices), Shift+Enter = new line, arrows only cycle the type while the text has no newline. The save button is disabled for the few ms module states load (it used to return silently) – e2e specs that click "Speichern" right after `goto` wait for it automatically.
- **E2E gotcha:** rows render before module states load; wait for `capture-row-type` to have a value before pressing Enter (see `e2e/capture-multi.spec.ts`).
- **Tray "Heute":** routes never cross to Rust; Rust only knows ids `today-0..4`, `now`, `timer` (constant eval scripts). Sources are allow-listed (`TRAY_SOURCES` = todos, calendar). Timer engine is imported on click only (keeps it out of the start bundle; T6 cares).
- **Open:** "Jetzt dran anfangen" opens the focus screen of the first ToDo line, else the first line; a smarter pick (`modules/todos/next.ts` pickNext) would need a public todos API. Idea 11 (home-screen widget) not started.
- **Finding outside my scope:** `docs/user/modules.md` (+ `.de.md`) still says the native Android APK has no share target; the `share-intent` plugin (`src-tauri/plugins/share-intent`) provides it. Whoever owns user docs: check and fix.
