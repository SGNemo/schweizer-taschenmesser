# Brand assets – sources and licences

- **Logo (clownfish), name "NEMO" and app icons** – drawn for this project (`logo-mark.svg`, `logo-mono.svg`, `logo-wordmark*.svg`, `app-icon*.svg`, `android-*.svg`): the fish from a few Bézier shapes, the lettering from stems, bars, diagonals and a circle (no font, no outlines of a typeface); no third-party artwork. Written by `design/logo-v2/export.mjs`, rendered by `npm run gen:icons` (`scripts/gen-icons.mjs`).
- **Inter (variable)** – app typeface, shipped locally through `@fontsource-variable/inter` (SIL OFL 1.1, © The Inter Project Authors, see `LICENSE-Inter.txt`).
- **Lucide icons** – ISC licence (`lucide-react`).

The About section in the settings shows the same notices (`about` in `src/strings.ts`).
