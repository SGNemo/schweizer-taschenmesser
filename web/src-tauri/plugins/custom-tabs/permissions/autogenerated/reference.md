## Default Permission

Open an http(s) address in a Custom Tab.

#### This default permission set includes the following:

- `allow-open`

## Permission Table

<table>
<tr>
<th>Identifier</th>
<th>Description</th>
</tr>


<tr>
<td>

`custom-tabs:allow-open`

</td>
<td>

Enables the open command without any pre-configured scope.

</td>
</tr>

<tr>
<td>

`custom-tabs:deny-open`

</td>
<td>

Denies the open command without any pre-configured scope.

</td>
</tr>
</table>
