## Default Permission

OS keystore for small secrets, the biometric gate for the vault key and screenshot protection.

#### This default permission set includes the following:

- `allow-available`
- `allow-set`
- `allow-get`
- `allow-delete`
- `allow-biometric-seal`
- `allow-biometric-unseal`
- `allow-biometric-has`
- `allow-biometric-delete`
- `allow-set-secure-window`
