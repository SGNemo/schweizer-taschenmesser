# Toolbar & tools, maps/share/launcher (Phase 13 steps 5–6)

Part of the architecture notes ([index](../architecture.md)); map of paths: [ARCHITECTURE-MAP](../ARCHITECTURE-MAP.md); decisions: [DECISIONS](../DECISIONS.md).

**Toolbar & tools (Phase 13, step 5)** – `web/src/tools/<id>/`, `core/tools/`, `core/calc/`, `layout/ToolsSheet.tsx`, `pages/ToolLibrary.tsx`.
- **Tools are not modules:** small self-contained helpers (no data of their own, nothing synced except *which* are on and their order). Each is `tools/<id>/manifest.ts` (`ToolManifest`: id, name, icon, description, `group` basis|extra|dev, `offline`, `defaultEnabled`, `order`, lazy `component`), discovered by `import.meta.glob` in `core/tools/registry.ts`. State = synced `_settings` scope `tools` `{ enabled: Record<id,bool>, order: id[] }` (`layout.ts` pure and tested; `useTools()`). **Isolation:** tools may not import modules, connectors, `core/db`, `core/ai` (ESLint block for `src/tools/**` + `tools/isolation.test.ts`, which also forbids tool→tool imports except `shared.ts`); modules may not import tools. Persisting anything goes through `useSettings` (scope `tools.<id>`, e.g. the scratch pad).
- **UI:** top-bar button "Werkzeuge" opens `ToolsSheet` (a `Dialog variant="sheet"`, tile grid of the enabled tools; a tile opens the tool in the same sheet, the dialog title becomes the tool name; "Werkzeuge verwalten" → `/tools`). `/tools` (`ToolLibrary`) = switches, offline badge, up/down order, "open". Tool components are lazy (one chunk each, created once outside render).
- **Shipped tools.** Basis (on by default): `calc` (history in `localStorage`), `percent` (part / share / VAT net↔gross), `currency` (Frankfurter = ECB reference rates `api.frankfurter.dev/v1/latest?base=EUR`, cached in `localStorage` `tm-currency-rates`, works offline with the cache; **the only online tool**), `timer` (timer/stopwatch/pomodoro; a zustand engine keeps them running while the sheet is closed, notification when done), `qr` (`qrcode-generator` → SVG, save via `PlatformService.saveFile`; scan with `BarcodeDetector` + camera where supported), `scratch` (one synced note). Extra (off): `units`, `split` (bill split + tip), `dates`, `dice` (uses `core/crypto/random`, rejection sampling). Dev (off): `base64` (UTF-8 base64 incl. URL-safe input, URL encode/decode), `json`, `uuid`, `hash` (WebCrypto SHA-1/256/512).
- **Calculator (`tools/calc`, engine `core/calc/`):** six tabs – Standard and Scientific (`ExprMode`: live result, keys, `a = 19 %`, `ans`, history with search, "save as note"), Programmer (`ProgrammerMode`, `core/calc/programmer.ts`: BigInt, word size 8–64, signed, hex/dec/oct/bin), Percent & finance (`FinanceMode`: percent/VAT, discount, compound interest, annuity loan in `finance.ts`, split & tip), Date (`DateMode`, `core/calc/dates.ts`: difference, plus/minus days to years, working days Mon–Fri) and Units (`UnitsMode`, `core/calc/units.ts`). `engine.ts` wraps **mathjs** (lazy chunk, BigNumber, locked down; offline fallback = the old parser `expr.ts`, which still backs `percentOf`-style phrases); `numbers.ts` reads locale numbers; `session.ts` keeps variables for the session. The last tab and the angle unit live in settings scope `tools.calc`. Decision: [decisions/tools.md](../decisions/tools.md).
- **Palette calculator:** `layout/CommandPalette.tsx` offers a `calc` option after the matching commands and before "Assistent fragen". Synchronous (`core/calc/phrases.ts` `calculate`): arithmetic ("240 + 19%"), "19% von 240", base conversions ("0x1F in dez") and date phrases ("15.03. + 45 Tage", "15.03. bis 30.04."). With a leading `=` the full engine answers ("=sqrt(2)*3", async, 120 ms debounce, errors are shown as text). Enter copies a plain number (locale decimal mark, no grouping) and keeps the palette open. Purely local, 0 tokens, never reaches the assistant/cache.

**Maps, WhatsApp, share page, Lesezeichen (Phase 13, step 6; since 0.5.0 a view of `bookmarks`)**
- **Links out** (`core/links.ts`, tested): `mapsUrl(place)` = `https://www.google.com/maps/search/?api=1&query=…` (calendar event editor and the read-only external event detail show "Auf der Karte zeigen" when a place is set; the Maps app takes over on Android), `whatsappUrl(text)` = `https://wa.me/?text=…` (birthdays row button, no phone number: the contact is chosen inside WhatsApp; no unofficial libraries). Both open through `PlatformService.app.openUrl`.
- **Share page `/share`** (`pages/ShareTarget.tsx`): the PWA manifest's `share_target` now points here (a manifest allows one target). It shows what was shared (`title`/`text`/`url`; a link inside `text` is recognised) and offers only *enabled* modules: Merkliste (`/bookmarks?title&text&url`, unchanged and still usable directly), Notiz (`/notes?new=1&title&text`), ToDo (`/todos?new=1&title`); notes and todos prefill their create dialog/field from those parameters. The page itself imports no module. **Not built:** a native Android share target for the APK (needs a Kotlin plugin + manifest merge that can only be verified in the Android CI job and on a device) – the share menu works for the installed PWA only.
- **Module `launcher` (retired in 0.5.0):** its links are copied to `bookmarks_item` (`kind: link`, `tags: [group]`) by the app migration `0.5.0-launcher-link`; `normalizeLaunchUrl` stays in `launcher/schema.ts`. The bookmarks page shows them as tiles (`?view=links`, groups = first tag, a tap opens via `getPlatform().app.openUrl`).
- **Spotify connector: built later as `connectors/spotify` (see [features/spotify.md](../features/spotify.md)); the note below is the original reason it was postponed.** The Spotify docs host is unreachable from the build environment and public reports (Feb 2026: development-mode apps need a Premium owner, max. 5 users, one client ID per developer, endpoint changes announced/postponed) show that the API differs from what the plan assumed. Per the plan's stop rule it was left out instead of guessing; the launcher preset "Spotify" opens the web player. Adding it later = one more `connectors/spotify` folder plus a widget hook (see "Connectors").
