# Design rules (look "Klar", flat, calm)

For every new module, tool and component. Moved unchanged from CLAUDE.md. Token mechanics and brand pipeline: [design-brand.md](design-brand.md). Index: [HOW-TO](../HOW-TO.md).

- **Tokens, never hard-coded values.** Colours, radii, shadows, spacing, type sizes, weights, z-index, durations come from `web/src/ui/tokens.css` (`var(--…)`). No hex/rgb in module CSS, no own `border-radius`/`box-shadow`/`z-index`/`font-weight` numbers (use `--weight-medium/semibold/bold`, `--z-*`, `--text-3xl` for hero numbers). Modules inherit the look through `@/ui`: Button, Card, Fields (`TextField` with `labelHidden` for inline add rows), Dialog, Patterns (`Segmented`, `ItemRow`, `Progress`, `Chip`, layout utilities `patternStyles.hstack/plainList/gapBottom/inlineForm`), Misc (`Badge`, `EmptyState` incl. `compact`, `Skeleton`), `WidgetList` for dashboard widgets. Never re-implement a segmented control, progress bar or input in a module; no inline `style={{}}` for layout or colour.
- **Surfaces (Klar 2):** solid cool `--bg` page, `--surface` cards/widgets/panels at level 1 (`--shadow-1`, no border), `--surface-2` for quiet areas and control tracks, `--shadow-2` for floating layers (menus, dialogs, sheets, FAB, toast). `--border` = hairline row dividers, form controls use `--border-strong`. Radii: sm 8 / md 12 / lg 16 / xl 20. Focus = 2 px `--focus` outline + 2 px offset (no ring shadow). Meta text `--text-3` at `--text-meta`; list rows `min-height: var(--row-h)`, grid gaps `var(--grid-gap)` (density setting).
- **One accent, one job:** filled `--accent` only for the page's primary action and the FAB; everything else (tabs, chips, nav, links, active states) uses `--accent` as text/icon colour or `--accent-soft`. Status colours `--danger/--success/--warning/--info` (+ `-soft` = 15 % `color-mix`, never hex), charts `--viz-1/--viz-2`. Amounts and dates: `font-variant-numeric: var(--font-num)`. The ocean gradient (`--ocean-from/to`) is brand only (splash, empty states, images), never a page background.
- **Contrast:** WCAG AA (4.5:1 text, 3:1 UI). `ui/tokens.test.ts` checks the palette incl. `--text-3`, `--border-strong` on `--surface-2` and the status mixes; a new colour token needs a light and a dark value and an entry in that test. Touch targets ≥ 44 px (`--touch`), inline checkboxes 24 px.
- **Motion:** CSS only, `transform`/`opacity` only (progress bars scale, nothing animates width, colour or shadow), 120–250 ms (`--dur-fast/--dur/--dur-slow`, `--ease-out`), no endless animation except the `Skeleton` shimmer. Everything must be fine with `prefers-reduced-motion`. Loading: `Skeleton`, not spinners or "…".
- **Empty and error states:** `EmptyState` (page) or `EmptyState compact` / `WidgetList empty` (widgets): the faded Nemo fish, one sentence, at most one button; no icon prop, no module illustrations. Loading = `Skeleton`/`SkeletonRows`, errors inline with `ErrorState` (sync errors in the shell banner).
- **Brand:** the fish is defined once in `design/icon/final.params.mjs`; `npm run export` (in `design/icon/`) writes `web/brand/*.svg` and the generated blocks in `Logo.tsx` and the splash, `brand-sync.test.ts` enforces they agree. Icons: `docs/HOW-TO.md` → Icons. Special styles (QR black/white) need a comment and an entry in `docs/DECISIONS.md`.
- **Checking a design change:** `SCREENS_SCHEME=dark SCREENS_VIEWPORTS=1280x720,412x915 SCREENS_PAGES='^(dashboard|finance-overview)$' npm run screenshots` renders invented data; `SCREENS_CSS=<file>` injects token overrides for experiments; `npx playwright test e2e/a11y.spec.ts` runs axe in both themes.
- **Navigation (Klar 2):** every module declares `area` (`plan|money|household|knowledge|vault|system`); areas group the sidebar/rail/bottom nav and show as tabs above the page (`layout/AreaFrame`), nothing else – never import across modules for it. One filled "+ Neu" in the top bar on desktop, the FAB only below 900 px. Pages never set their own sidebar/rail assumptions; split views use `SplitView` (from 1200 px) and `useSplitView`. Favourites ≤ 5 via `core/settings/nav.ts`.
- **Components (Klar 2, Phase 3):** buttons `primary` (once per view) · `secondary` · `ghost` (quiet) · `danger` (confirm dialogs) · `quietDanger` (row delete) · `size="sm"`; lists are `ItemList` + `ItemRow` (flat rows, `layout="grid"` = tiles), sub-views `Tabs`, filters `Segmented`/`Chip`, forms `TextField`/`DateField`/`SelectField`/`Checkbox`/`Switch` with `error`; a `Dialog` is a bottom sheet on phones (`dirty` asks before discarding, `useDraft` keeps a draft 30 s). Every state-changing list action goes through `undoableWithToast` (`core/undo`): toast with "Rückgängig" + Ctrl+Z. Keyboard hooks on rows: `data-row` (set by `ItemRow`), `data-row-edit`, `data-row-tick`; list search gets `data-list-search`. Selection: `useSelection` + `SelectionBar`; touch: `onSwipeRight/Left` on `ItemRow`. All of it is on the dev page `/dev/components` (Dev-Preview/E2E only).
