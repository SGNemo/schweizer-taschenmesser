# Planner (`modules/planner`) – how it works

Part of [planning-modules.md](planning-modules.md) (the other Planen modules). Concept: [design/planner-rethink](../design/planner-rethink/README.md); decisions: [decisions/plan.md](../decisions/plan.md).

- **Data:** `planner_day` (id = date; `availableMin?`, `blockers[]`; only touched days), `planner_item` (id = `<module>:<id>`; `excluded`, `splittable`, hard `due`, overrides, `earliest` = the user's date before the overwrite), `planner_assignment` (id = `<itemKey>#<k>`; day, minutes, order, `locked` = „fest“, reason). All writes through `putRow` (restore if tombstoned, then `upsert`), plain indexes. `dataApi: false`, no `aiSchema`, `requires: ['todos']`, `maturity: 'preview'`.
- **Engine (`core/plan`):** `plan({ today, days, items, prev, loose, settings })` → assignments, unplaced, diff, load, `kept`. With `loose` (every caller passes it) the plan **stays put**: a unit with a stored day inside the planned days is set there first whatever the room, one on a passed or far day is left alone (`kept`), one without a day gets none (`no-day`); only the items named in `loose` go through the rules (hard due → priority → age). Tests: `stays.test.ts`; the fixtures still cover the rules for loose items.
- **Run (`run.ts`):** inputs as before; `runPlanner(deps, { loose, touched, ops, reshuffle })`. Rows are written in place and keep `locked`; a run removes rows only for „Nicht planen“ and late money – never for a done, unlisted or missed thing (the board hides those). Write-back (`onAssign`) only for the things an action named (`loose ∪ touched`); a pass nobody asked for writes no row and tells no source anything. `looseOf` reads what a sentence hands over.
- **Service (`services.ts`):** the live query still starts a pass (it refreshes `lastRun`: things without a day, titles) but moves nothing; `runUser(label, act)` = action + run in one `undoable`, `act` returns what it named (`{ loose, touched, ops }`); `migrateModel.ts` turns the pins of before into `locked` rows once the sync has settled; `module.disabling` as before.
- **UI:** `routes/PlannerPage.tsx` (tabs „Plan“ · „Noch offen“ = rows on passed days, `?tab=open`; head figure; field → the new thing lies on the day on the sheet; seven days from today; rows = title + minutes, „fest“ for a locked row; „Verschieben …“ = `moveTo`, „Fest an diesem Tag“ = `setLocked`; group „Noch ohne Tag“). „Tage einteilen“: `components/DaySetup.tsx`, `daySetup.ts`.
- **ToDo side:** `plannable.ts`, `planMark.ts` (restore when stored off + gate open), `views.userPlannedFor` for every writer, `dayPlan` by `planMark.order`, „Neu planen“ hidden while on, „im Plan: Mi“ in Bald.
- **Package 2:** `calendar.ts` (chip per day); capture target `plan`; `core/plan/instructions.ts` → `PlanPreview` → `applyOps`; see [decisions/plan.md](../decisions/plan.md).
