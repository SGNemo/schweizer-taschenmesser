# Use case „Wochenende retten“ – analysis (phase 1: play-through, measurement, friction)

Branch `design/usecase-wochenende`, 2026-11-14, `develop` @ `35499492`. Scenario by the maintainer (verbatim in the prompt, condensed): _Saturday morning, first use of the app; lay out Saturday, Sunday and the next days; log work time, answer WhatsApp, check and answer mails (find the important ones, search one, take invoices from them), after the gaming break tidy the flat, shower, gather the bottle deposit; what is left gets spread over other days „per Klick“; less gaming, more doing; by Sunday everything answered and the team stuff read, so Sunday evening there is time to see how he feels (call in sick Monday); fix the sleep rhythm._ Target picture: [TARGET.md](TARGET.md), packages: `PACKAGES.md` (after the stop). Measurement script: [`web/e2e/usecases/wochenende.spec.ts`](../../../../web/e2e/usecases/wochenende.spec.ts). Known findings are only referenced: [kopf-leer](../kopf-leer/ANALYSIS.md) (K…), [round 5](../../../qa/round-5.md), [round 6](../../../qa/round-6/FINDINGS.md). Nothing here is code.

## 2. Play-through and measurement

Played on an **empty install** (no seed, no test data) of the e2e build (`npm run build:e2e && npm run preview`, same app as `npm run dev:all` without the sync server), clock fixed to Saturday 2026-11-14 08:30 (path F 21:00), desktop 1920 × 1080 and Pixel 7 (412 px), light and dark (screenshots in the PR text). The mail path runs on the seeded Dev-Preview (`USECASE_SEED_URL`, clock of the seed, as in kopf-leer); connecting Gmail cannot run here and is counted by hand. Counting model as in kopf-leer: tap = touch/click; keys = typed characters (Enter = 1); screens = routes the person has to find; dialogs = sheets, dialogs or previews to read; detours = the app did something else than meant. ## 4. What already works (keep)

- The batch of twelve lines saves in one tap, never books, and closes calmly („12 Dinge gespeichert. Sortiert wird später.“) – kopf-leer F1 carries here.
- „So 19 Uhr erinnere mich …“ is a reminder at 19:00 on Sunday; reminders never block plan time.
- Mail: „Persönlich“, the invoice line „Anlegen“ and „In den Plan“ are one tap each (kopf-leer 3a/3b) – once Gmail is connected.
- The planner field already understands „Sa 6 Std“, „So frei“, „Sa 14 bis 16 Uhr Zocken“ (a blocker with times), „schieb X auf Mo“, „alles von Sa nach Mo“ – it only is not offered (W09, W12).
- Nothing in the app counts, rates or locks leisure; the focus settings default to calm (no streaks, no morning digest).
