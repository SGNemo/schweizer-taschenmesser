## Packages (each its own branch and PR, mergeable alone)

1. **P1 `feat/settings-more-p1` – Sicherheit, no new crypto.** The tab exists without the vault. "Schutz auf diesem Gerät": screen guard only-vault / whole app (Android FLAG_SECURE, refcounted so leaving the vault never drops the app-wide guard), "Nur verschlüsselte Backups" (hides every readable download: settings form, Gerätestatus dialog, setup step, switch to home network), "Fehlerbericht ansehen" (link to the existing preview). Vault: clipboard time 10 s / 30 s / 1 min / 2 min. "Zugriff auf dieses Gerät": read-only rows (sync, paired LAN devices, remote control, local API accesses, browser extension, share pairs), each leads to where the access is ended. All new values device-local (`core/security/prefs.ts`), never in profiles, history or the settings file.
2. **P2 `feat/settings-more-p2` – App-Sperre.** PIN (verifier only, in `getPlatform().secrets`), unlock with biometrics where the device has it, lock after 1/5/15/30 min idle and on minimise (now / 30 s), retry delay after wrong PINs; the app's content is unmounted while locked. Council (Guardian) before the PR. Honest wording: a privacy lock, not encryption (the vault keeps its own).
3. **P3 `feat/settings-more-p3` – Allgemein extras.** Trash keep time; start page; 12/24 h if the format layer allows it without touching every caller.

Not planned: corner-radius step (needs `ui/tokens.css`, a hotspot of another chat) – in the PR under "Noch offen".
