# Round 2 – Full home page, two layouts

Chosen in round 1: direction **C** (warm wash with faint fish silhouettes, claim "Alles Wichtige an
einem Ort. Und nur bei dir.", download card, PC + phone) with **B**'s mini-screenshot tiles; both
download buttons filled.

Both layouts share the same sections in the same order: hero · Was Nemo kann (6 tiles) · Deine
Daten bleiben bei dir (flow graphic + what the cloud AI gets) · Gemacht für volle Köpfe (4 aids,
one honest sentence, no promise) · video (poster + play, no autoplay, reduced motion = still) ·
Vergleich (5 rows) · Unterstützen (Ko-fi + the five supporter themes) · Installation (collapsible) ·
footer. Mini-screenshots are crops of the one overview image for now; real per-module shots and a
clean hero shot come with the screenshot automation in round 3.

| | Layout 1 – Bänder (`layout-1.html`) | Layout 2 – Zick-Zack (`layout-2.html`) |
|---|---|---|
| Rhythm | One column; every second section is a tinted band; focus aids and video centred | Text and visual side by side, sides alternate; hairlines between sections |
| Focus aids | 4 columns with icons, centred | List with icons beside a cropped "Jetzt dran" screenshot |
| Video | Full width (max 56 rem), centred, caption below | Half width beside two lines on quick capture |
| Vergleich | Table, 3 columns | Two cards side by side, Nemo outlined in accent |
| Unterstützen | One card (text, themes, button) | Text left, themes right |
| Desktop length | ≈ 5 300 px | ≈ 5 500 px |
| Phone length (360) | ≈ 7 900 px | ≈ 8 600 px |
| Strength | Calmer, more editorial, easier to scan in one line; least CSS | More visual evidence per section; feels more like a product page |
| Risk | Centred text blocks can feel like a brochure | More images to keep current; the zig-zag collapses to the same column on phones |

**Recommendation:** Layout 1. It keeps one reading line, scans fastest and fits the focus rules
(one thing per band). Take the "Jetzt dran" crop from layout 2 into the focus band if a visual is
wanted there.
