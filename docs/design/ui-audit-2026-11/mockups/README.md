# Mockups – Identity 4.0 (Zielform, kein App-Code)

Drei Seiten als HTML auf der Basis der Identity-v3-Mockups (`docs/design/identity-v3/mockups/`, Palette v3 und Marken unverändert), mit der Ebene `v4.css`, die die fünf 4.0-Regeln zeigt: Tonstufen statt Schatten, eine Titelzeile mit Tabs, Navigation in einer Ebene (keine Sub-Navigation am Desktop, eine Modul-Zeile unter dem Kopf am Handy), ein neutrales „Neu“ plus eine Modul-Aktion, Dichte je Gerät (Master–Detail, Lesemaß, Inhalt ab Bildschirm 1). Rendern aus `web/`: `node ../docs/design/ui-audit-2026-11/mockups/render.mjs` → `web/.screens/ui-audit/mockups/` (gitignored). Die Bilder liegen auf dem Branch `shots/ui-audit-2026-11`:
