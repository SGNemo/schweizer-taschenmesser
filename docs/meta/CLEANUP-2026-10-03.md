## What was done

- `chore(strings)`: removed 20 unused German strings. `backup.mergeHint` and `backup.replaceHint` looked unused by grep but are read dynamically (`${mode}Hint`, found by the typecheck) and were kept.
- `chore(web)`: removed unused CSS-module rules (`reminders`, `DrivesPage`, `ScanPage`, `Page`), unused barrel re-exports (`ui/index.ts`, `ui/widgets/index.ts`) and `Tree::root_path` in `disk-scan` (crate tests green).
- `refactor(core)`: `pantry/schema.ts` uses `DATE_RE`; `core/update/backup.ts` uses `stampOf` instead of a copy. The same change in `calendar/settings.ts` (`TIME_RE`) was **reverted**: together with the other two it made `E2E app (shard 2/4)` fail deterministically in CI (`newmodules.spec.ts:42`, pantry hand-over), while all tests passed locally. Bisect on CI: reverting the whole commit = green, pantry schema alone = green; the final state without the calendar change = see PR. Root cause not found (candidate: importing `core/time/dates` into the eagerly loaded calendar settings changes module load order); left as a proposal in the improvements file.
- `chore(web)`: reasons for three `eslint-disable`, per-field store selectors in `ToolsSheet`, removed a double cast in `TaskEditor`, `HIGHLIGHT_MS` constant, `e2e` script chains `e2e:app` and `e2e:sync`.
- `test`: removed 6 tests, see below.
- Docs: this file, `IMPROVEMENTS-2026-10-03.md`, a "no copies of helpers/components" rule in `docs/RULES.md`, a ROADMAP link. `CHATS.md` row removed.
