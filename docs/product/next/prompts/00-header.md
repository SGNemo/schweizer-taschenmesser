# Common header (paste first into every chat)

Identical to the round-5 header in [../../focus/15-parallel-prompts-4.md](../../focus/15-parallel-prompts-4.md) so all parallel chats follow the same rules. T3 is the one chat allowed a single stop (see its block).

```
Lies CLAUDE.md und docs/README.md, dann nur die Docs deines Bereichs. Git: docs/PROMPT-TEMPLATES.md#git · Regeln: #hard-rules · Docs: #knowledge · PR-Text: #pr-text.
Arbeitsweise: Du arbeitest allein und stellst KEINE Fragen. Wo eine Entscheidung offen ist, wähle die sicherere, ruhigere Variante (docs/design/FOCUS-GUIDELINES.md: kein Druck, keine Schuldtexte, alles abschaltbar, Frage 9 "Was könnte stattdessen weg?"), schreibe die Entscheidung als ein Bullet in docs/decisions/<bereich>.md und in den PR-Text unter "Entschieden ohne Rückfrage". Nur bei hartem Blocker (Sicherheitsregel würde verletzt, neue Abhängigkeit nötig, Konflikt in Datenmodell/Registry): stoppen und den PR-Text mit dem Stand ausgeben.
Scribble (Pflicht, scribble/README.md): (a) Start: `cd web && npm run chats:status`, scribble/BOARD.md lesen. (b) Vor dem ersten Code-Commit eine Heads-up-Zeile in BOARD.md (Datum · Branch · Dateien), direkt auf develop gepusht nach README "Pushing" (nur scribble/ im Commit, `chore(scribble): …`). (c) Fragen an andere Chats und Funde außerhalb deines Bereichs ebenfalls dorthin, nicht an den Maintainer; Antworten auf Fragen anderer Chats gibst du dort, wenn du sie weißt. (d) Ende: scribble/<branch mit - statt />.md mit "for the next chat:" (Gotchas, Offenes) im PR; Heads-up-Zeile abhaken.
Pflicht: Zeile in docs/CHATS.md im ersten Commit (die "(announced)"-Zeile deines Branches übernehmen), im letzten Commit entfernen. Alle UI-Texte in 5 Sprachen (npm run check:i18n). Nichts am Datenschutz der KI ändern (nie Nutzerdaten an die KI, privacy.test.ts), keine neuen Abhängigkeiten (npm und Cargo), keine Tests löschen oder abschwächen; Specs, die durch eine Faltung nicht mehr an ein Element kommen, öffnen die Gruppe zuerst (`openFoldedGroup(page, section, id)` in e2e/helpers.ts). Nichts entfernen: Was weniger sichtbar wird, bleibt erreichbar (Falten, Menü, "Erweitert"), kein gespeicherter Wert, kein Default ändert sich. Jede Änderung mit Unit-Tests; E2E für sichtbares Verhalten (Desktop + pixel-7). Vor Abschluss develop mergen (Merge, kein Rebase), `npm run check`, `npm test`, `npm run e2e`, `npm run check:docs` grün (STATUS.md hat 5000 Token Budget: eine Zeile ändern, nichts anhängen). Ein PR gegen develop, nicht mergen. Schlussmeldung: 3 Punkte + PR-Link.
Dateibesitz: nur die im Prompt genannten Bereiche; fremde Dateien nur klein und additiv, kein Umbau. Hotspots (docs/CHATS.md unten) nur mit Heads-up.
```
