# Decisions – Tools

- **Screenshot tool (2026-10-19, focus audit 2, package 4b):** `tools/screenshot`, group extra, **off by default** (a daily function for one person, one more entry for everyone else), the toolbar/library like any tool. Browser/desktop app: `getDisplayMedia` → one frame → PNG on the page; Save (`getPlatform().saveFile`) or Copy (clipboard image); nothing is stored or sent, the picture is gone on discard. A dismissed picker is "Nichts aufgenommen.", not an error; phones and webviews without capture get a plain explanation and no button. No new dependency, no new data flow (the picture never leaves the page). Rejected: a home widget (a button that needs a picker prompt is not a glance), "into a note" (tools never write to modules). A shortcut for it comes with the shortcut map (4c).
