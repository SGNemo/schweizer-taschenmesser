# Decisions – languages (docs and UI)

Index: [DECISIONS](../DECISIONS.md).

- **Docs source language is English; README and user docs also German** – 2026-10-06. The repo goes public for international visitors; German users keep full user docs. German copies sit next to the source as `*.de.md` (`README.de.md`, `docs/user/<name>.de.md`, `docs/AI-IMPORT.de.md`) instead of a `docs/de/` tree, so relative links keep their depth and pairs are easy to compare. `npm run check:readme` (CI job `docs-pairs`, blocking) keeps headings, `<details>`, links and images in step. Developer docs are English only; German stays where it is internal or legal (STATUS "Offen – macht Sven", MANUAL-TESTS, `legal/`, `design/FOCUS-WORDING.md`, archive). Rejected: `docs/de/` mirror (deeper links, harder pairing), English only (German users are the current audience).
- **Brand claim per language: "Notes · Events · Modules · Offline" / "Notizen · Erinnerungen · Module · Offline"** – 2026-10-06. Keeps the NEMO backronym; `gen:icons` renders English images under the existing names and German copies as `*.de.png`; the German-default website keeps the German OG image.
- **App UI in five languages (de source, en, es, fr, pt-BR), typed TS catalogs instead of JSON/ICU** – 2026-10-07. `t` is a view over the German source that resolves each read through current language → English → German, so call sites stayed `t.area.key` and a switch needs no reload (catalog loads, app remounts). Catalogs are TypeScript part files typed by the source's shape (the compiler finds missing keys; plurals are small functions using `Intl.PluralRules` helpers) instead of JSON with ICU MessageFormat (no new runtime, no string parsing, no second key system). Default is the system language, else English; installations that already had data keep German. Formats follow the language unless a region is chosen. Translations are machine-made with a glossary and marked as such ([i18n/README.md](../i18n/README.md)); parsers (quick capture, AI rules, calculator), seeds, AI prompts and legal texts beyond German/English stay as they are. Rejected: i18next/FormatJS (runtime + migration of 3 400 keys for no gain), reload on switch.
- **Tresor-Stärke (QA P3b):** das Stärke-Label folgt der gezeigten Offline-Knackzeit (kleinerer Wert aus zxcvbn-Score und Zeitstufe), die Warntexte kommen aus den fünf Katalogen (`accounts.strength.warnings`), die Bibliothek liefert nur Schlüssel. Nur UI, keine Krypto-Änderung.
- **Formate:** Anführungszeichen, Wochenzahl („KW/Week/Semana“), Tagesliste ohne Ordinalpunkt und „Uhr“ gelten je Sprache (`quoted`, `PATTERNS`, `time.atClock`); Monatsnamen nur am Anfang groß (CSS `::first-letter`). `es-MX` ist als Format-Region wählbar; Währung je Konto/Rechnung bleibt ein eigenes Paket (Datenform).
- **Test data follows the UI language (QA, package 1):** `SeedContext.lang` + `ctx.text({ de, en, es, fr, 'pt-BR' })`; `applySeed` takes the UI language (`opts.lang` overrides), a missing language falls back to German. Ids, dates and numbers never depend on it, so counts and E2E snapshots stay stable. Replaces "seeds stay German" (2026-10-07) for screenshots per language; all seed modules are migrated (packages 1–3; chat already reads `t`). Company names, street addresses, people's names and file names stay as invented. Known gap: finance's real default account/categories (`ensureDefaults`) are still created in German.
