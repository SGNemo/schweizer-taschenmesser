# Decisions in full – Core – remote control (package 5)

Part of [core](core.md). Index of areas: [DECISIONS](../DECISIONS.md).

- **Remote control package 5: the widget's one action, user docs, maturity stays `preview` (2026-11-11, `feat/remote-polish`):** the home-screen widget (`modules/remote/widgets/RemoteWidget.tsx`, catalogue type `StatusWidget`) gets its one action "Wiedergabe / Pause". **Being shown opens nothing**: the widget only subscribes to the app's one session (`modules/remote/session.ts`) and shows what the phone knows by itself (paired or not); a test lets it stand for more than a second and counts zero opens. **The tap is what connects**: it calls `remoteSession.send('play-pause')`, the same path a key of the page takes (without a session the press opens one and goes out once it stands) – no second way to the PC, no own client, no own retry. The volume shows only while that session is open (`view.kind === 'connected'`); when the PC ends the idle session the line is "Dein PC" again and nothing reconnects by itself. **A session the widget opened is the widget's to end** – when the home screen is left or the app goes to the background; a widget that was never tapped closes nothing (the session could be the page's). Between the tap and the PC the line reads "Verbindet mit deinem PC …" (a still text, no spinner). A connect that takes longer than a press waits lets the press go (the session's own rule); if it then stands after all, the card says "Verbunden. Tippe noch einmal." instead of looking as if the press had gone out (only the latest tap's result counts: an impatient second tap replaces the first, and the first one's "not sent" is not news). Sentences to act on are also in a polite live region for screen readers, like on the page. A tap that cannot be carried out shows that state's sentence (the same `describe` as the page) with its one step: into the module, to pairing, or to the module library (`stepLink` in `view.ts`, shared with the page and the pad). Deviation from CONCEPT §7 ("the next tap returns the widget"): `StatusWidget` has one action, so after such a sentence the widget offers the step and no second tap; it returns to "Dein PC" when the state does (a slow connect that still succeeds) or the home screen is opened again. Not built: more media buttons, a control on Android's lock screen or in the notification shade. **Maturity:** module and settings section stay `preview` – none of the hand tests FB1–FB19 has run on a real phone and a real Windows PC; `stable` is the maintainer's switch after them (STATUS and CHATS "Wartet auf Sven" name them). **User docs:** `docs/user/remote-control.md` and `.de.md` (what is needed, switching on, the levels, ending and switching on again), without technical words.
