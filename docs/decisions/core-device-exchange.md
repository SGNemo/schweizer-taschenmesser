# Decisions in full – Core – device exchange (phone ↔ PC)

Part of [core](core.md). Index of areas: [DECISIONS](../DECISIONS.md).

- **Own module „Austausch“ (`exchange`), area System, desktop + Android – not part of the AI chat or remote control (2026-11-16, `design/device-exchange`):** the AI chat would put device messages one slip away from the provider and need permanent exceptions to the AI privacy rule; remote control's rule forbids clipboard and files in either direction and is a grant to steer, not to receive. No `aiSchema`, not `searchable`, `dataApi: false`, in `BLOCKED_MODULES`. Source: [design/device-exchange/CONCEPT.md](../design/device-exchange/CONCEPT.md) §3.
- **Transport: handshake mode 4 on the LAN hub's listener (2026-11-16):** same keys, trust list, limits and home-network gate as modes 2/3, own tags `0x30–0x3f`, never mixed with sync or input; the phone always dials (Android never listens), the PC keeps a per-device outbox and hands it over on the next session the phone opens; the phone keeps the session open while the page is visible. Files in frames ≤ 65 494 B, one transfer per session, SHA-256 while writing, resume from a `.part` for 24 h. Prototype: ≈ 300 MB/s for the layer on one host, 0.2 ms per message. Source: CONCEPT §4, §10.
- **Storage (2026-11-16):** messages in `exchange_items` with `local: true` on each device (not synced, never in a backup, 30-day default retention); files only on disk (PC `Downloads/Nemo` chosen by a Rust folder dialog; phone app storage with Teilen/Speichern unter), never in IndexedDB or sync; paths only in Rust, no command takes a path; PC → phone files by reference with a change check; thumbnails small and local, never from SVG. Source: CONCEPT §5.
- **Security (2026-11-16):** own per-device grant at the PC, off by default, one click at first run with the paired devices preselected, stored device-local in `trust.json`, never set over the network, no native dialog (exchange cannot click; a full remote session can do anything anyway); up to 100 MB per file without asking; names cleaned (last segment, NFC, no control/format/bidi characters, reserved Windows names, ≤ 120 bytes, unique); Nemo never opens or runs a received file, risky extensions only with a warning and without _Öffnen_, Windows `Zone.Identifier` ZoneId 3; clipboard read only on a tap, never written automatically; nothing of it in logs or diagnostics. Hard-rule line proposed (package R, Sven merges). Source: CONCEPT §6.
