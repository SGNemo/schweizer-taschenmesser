# Decisions in full – Core – remote control (package 4)

Part of [core](core.md). Index of areas: [DECISIONS](../DECISIONS.md).

- **Remote control package 4, part 1: the PC types text and the keys of the fixed list (2026-11-11, `feat/remote-keyboard-host`):** package 4 is three PRs like package 3 – part 1 the PC side (this), part 2 the phone's client (text and key actions in `remote_client_send`), part 3 the page Tastatur. New file `crates/remote-input/src/keyboard.rs`: the keyboard part of `SendInput`, the second and last place that simulates input. **No "any key":** `Key` is the hub's list of sixteen, mapped one to one in the shell (`key_of`, written out – a key added on one side does not compile until it is decided there); the one combination (Alt+Tab) is one id, pressed and released inside one call, and if the system took only part of a call the releases are sent once more – no modifier stays down. No Windows key, no Ctrl, no Shift, no media or volume key (pinned by name in `tests/rules.rs`, together with the exact sets of virtual keys and flags). **Text is typed as Unicode units** (`KEYEVENTF_UNICODE`, each down and up): the characters arrive whatever the PC's keyboard layout is; a unit never becomes a virtual key. The hub already refuses control characters and over-long text and applies nothing on a locked PC; the keyboard file drops control characters and caps the length once more for itself (512 UTF-16 units, cut at a whole character). **Its own thread** (`remote-keys`), bounded queue of 32, one more is dropped: a line of text and the Enter after it keep their order; between keyboard, pointer and media there is no order (the hub checks the lock per record). The text is moved from the hub's action into the one action that types it, never copied; nothing is logged, counted or stored. `crates/lan-sync` is unchanged (it has carried `Key` and `Text` since 1a). Nothing changes for users yet: no client sends a key. **Not verified:** compiled and linted for `x86_64-pc-windows-msvc`, but nothing was typed on a real Windows PC (hand tests come with the page: umlauts, emoji, a long word, an elevated window, a locked PC).
