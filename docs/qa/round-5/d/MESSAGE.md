Hi Daniel,

hier ist die Testversion von Nemo (sie füllt beim ersten Start Beispieldaten ein, die sind unter Einstellungen → Entwickler wieder weg): <LINK-DEV-PREVIEW>

PC (Windows): die `.exe` aus dem Link laden und starten. Windows warnt vor einem unbekannten Herausgeber, „Weitere Informationen → Trotzdem ausführen“ (Details stehen auf der Seite).
Handy (Samsung): die `.apk` aus dem Link laden und öffnen. Android fragt, ob du Apps aus dieser Quelle erlauben willst; einmal zulassen reicht.

Für dich wahrscheinlich spannend:
1. PC und Handy koppeln: am PC unter Einstellungen → Sync & Backup „Gerät koppeln“, das Handy scannt den QR-Code (die Handy-Seite kommt gerade erst, falls sie fehlt: das ist bekannt).
2. Backup anlegen, App-Daten löschen, Backup zurückspielen und vergleichen; das Klartext-Backup kannst du im Editor lesen.
3. Deinen Obsidian-Export (Ordner oder ZIP) unter Notizen → Importieren einlesen und schauen, ob deine Ordner stimmen.

Unter Einstellungen → Verbindungen steht, was überhaupt ins Netz gehen kann, und was seit dem Start rausging; dein Netzwerk-Tab darf gern dagegen prüfen.

Sag mir ehrlich, was nervt oder fehlt: direkt per Nachricht an mich oder als Issue auf GitHub (Einstellungen → Über Nemo → „Fehler melden“).
