# Nachricht an D (von Sven, per Messenger)

Hi Daniel, hier ist die Testversion von Nemo: <LINK-DEV-PREVIEW> (sie füllt beim ersten Start Testdaten ein; weg damit unter Einstellungen → Entwickler → „Testdaten entfernen“).
PC: die `.exe` laden und starten; Windows warnt vor einem unbekannten Herausgeber, „Weitere Informationen → Trotzdem ausführen“.
Handy: die `.apk` laden und öffnen; Android fragt einmal, ob du Apps aus dieser Quelle erlauben willst.
Für dich wahrscheinlich spannend:
1. Abgleich im Heimnetz: am PC unter Einstellungen → Sync & Backup „Gerät koppeln“ ansehen. Die Handy-Seite (QR scannen) ist noch nicht drin, die kommt als Nächstes; sag mir, was dir am PC-Teil fehlt.
2. Backup anlegen (Einstellungen → Sync & Backup), App-Daten löschen (am einfachsten am Handy: Android-Einstellungen → Apps → Nemo Dev → Speicher → Daten löschen), Backup zurückspielen und vergleichen; die Datei ohne Passwort kannst du im Editor lesen.
3. Deinen Obsidian-Export (Ordner oder ZIP) unter Notizen → Importieren einlesen und schauen, ob deine Ordner stimmen.
Unter Einstellungen → Verbindungen steht, was überhaupt ins Netz gehen kann; dein Netzwerk-Tab darf gern dagegen prüfen.
Sag mir ehrlich, was nervt oder fehlt: per Nachricht an mich oder als Issue auf GitHub (Einstellungen → Über Nemo → „Fehler melden“).
