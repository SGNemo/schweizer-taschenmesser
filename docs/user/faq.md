# FAQ

## Why does Windows warn me on first start?
The exe has no purchased code-signing certificate. The update payload is still signed and the app checks it. Details: [Installation](installation.md).

## Is there an iOS version?
No. On the iPhone you can use the PWA in the browser (without push).

## Can I export my data?
Yes. Settings → Backup creates a file with everything except credentials; the vault has its own encrypted export. Details: [Backup](backup.md).

## Which languages does the app speak?
The interface is German today. More languages (English, Spanish, French, Portuguese) are in preparation. Your own entries are never translated.

## Isn't the project called "Schweizer Taschenmesser"?
That was the old name. Technical identifiers (package name, file paths) keep it so updates and data stay intact.

## Is Nemo free?
Yes, MIT licence. Costs only arise with paid AI providers that you set up yourself. Voluntary support is possible via [Ko-fi](https://ko-fi.com/nemojr) and only unlocks cosmetic extras.

## Does Nemo send my data anywhere?
No. Data stays on your device. Sync only runs through a server you operate yourself, and AI providers never receive your entries. Details: [Security](security.md).
